# Mathlete

Timed, fill-in-the-blank math practice for phones and iPads. Fifteen games, player profiles, and a review list that brings back missed facts until they are answered correctly three rounds in a row.

Open the site in Safari, tap Share, then "Add to Home Screen" to install it. Progress is saved on each device.

When `index.html` changes, bump `VERSION` in `sw.js` so installed copies pick up the update.
